# Changelog

## 1.0.0

First release.

- Adds the Cookie-Script.com banner script to the storefront, in the header or the body, first or last.
- Google Consent Mode v2: default state for the 7 consent types and "wait for update", with regional settings.
- Settings per website and store view (Stores > Configuration > CookieScript > Cookie Banner).
- Works with Content Security Policy in report-only and enforced mode.
- Saving the settings empties the Full Page Cache, so the change shows on the next visit.
